# Copias de módulos del Alfonso original no necesarias para el proyecto autónomo

Este archivo actúa como inventario de las funcionalidades copiadas desde el Alfonso original que no encajan en la ramificación orientada al cumplimiento local y autónomo ("One-Click AEAT").

Se incluyen copias de seguridad de las siguientes carpetas y archivos en esta carpeta compartida para futuras referencias o recuperaciones.

---

## 1. Módulos que no cumplen con SOLID o Clean Architecture en el contexto autónomo
*   **`comfy_tools.py`**: Automatización de generación de imágenes por ComfyUI/Stable Diffusion. Totalmente fuera del dominio de fiscalidad y tareas del autónomo.
*   **`instagram_tools.py`**: Automatización de posts y lecturas en redes sociales. No aporta valor directo para la presentación de impuestos y conciliación bancaria.
*   **`dev_agent.py` / `sandbox` (Parcial)**: Alfonso autónomo no necesita un compilador de código aislado para uso generalista ni un editor interactivo de software. La interacción con el navegador y OCR es suficiente.
*   **`detecionmicrosgoogle.py`**: Script experimental para la detección de micrófonos y hardware físico. Obsoleto y acoplado a dependencias del host de desarrollo original.
*   **`nueva_implementcion.md` / `Agente Local de Alfonso para Interacción con el Escritorio.md`**: Borradores y notas de diseño anteriores ya consolidadas.
*   **`comfy_tools.py`**, **`instagram_tools.py`**, **`market_research_tools.py`**.

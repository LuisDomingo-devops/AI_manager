# AI_Manager Constitution

## Core Principles

### I. Desarrollo en Español
Toda la comunicación, respuestas y explicaciones DEBEN proporcionarse exclusivamente en castellano. No se permite dar respuestas en inglés.

### II. Test-Driven Development (TDD) Estricto
Es obligatorio seguir siempre la metodología TDD (Test-Driven Development). Los tests deben diseñarse antes de la implementación del código.

### III. Cobertura de Pruebas Completa
Cada implementación de código llevará SIEMPRE asociada su correspondiente suite de pruebas, que incluirá obligatoriamente:
- Tests unitarios
- Tests de integración
- Tests de QA

### IV. Ejecución Continua y Registro de Tests
Después de cada implementación de código, se DEBEN ejecutar todos los tests de la suite. Tras cada ejecución de test, se debe crear un archivo de log que contenga los resultados de la ejecución de los mismos.

### V. Navegador Estándar
Para cualquier interacción o automatización web, no se debe usar Chrome como navegador; se debe utilizar Firefox exclusivamente.

## Governance

Esta constitución tiene prioridad sobre cualquier otra práctica de desarrollo. 
Todas las revisiones de código e implementaciones futuras deben verificar el cumplimiento estricto de estas reglas. Cualquier cambio en la constitución requerirá una revisión de la versión.
